# Corne-layout
My preferred layout for Corne split keyboard


Notable aspects:
- homerow mods and timeout config set to avoid weird behavior
- different tiling split options per layer
- zxcv are all configured for my most used vim behavior on hold, and system behavior on tap and hold
- screenshot and screen recording keys since I use them often enough in writeups
- symbol and number layer with surrounds (){}[]'" on the right side and numpad keys on the left
- system features on layer 3
